# ShopCart E-commerce Storefront

A polished, responsive e-commerce experience built with plain HTML, CSS and JavaScript. It focuses on strong UI fundamentals without depending on a framework.

## Highlights

- Responsive product catalog
- Category filtering, text search and sorting
- Shopping cart with quantity controls
- Cart persistence using `localStorage`
- Accessible labels, keyboard Escape support and live status messages
- Custom lightweight SVG product artwork
- Mobile-first responsive layout
- No dependencies or build step

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Skills demonstrated

HTML5 semantics · CSS Grid and Flexbox · Responsive Design · JavaScript ES6+ · DOM APIs · Event Handling · Local Storage · UI/UX
